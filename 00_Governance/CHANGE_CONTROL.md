# Change Control

No major change is accepted from conversation alone.

## Change Process

Proposal:

1. Problem
2. Expected benefit
3. Cost
4. Test method
5. Success criteria
6. Decision

## Examples requiring review

- Changing account positioning
- Adding new tools
- Changing content strategy
- Automating publishing
- Expanding scope

## Principle

Execution first. Optimization second. Expansion last.
