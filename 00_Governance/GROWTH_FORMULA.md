# China Tech X Growth Formula Discovery — v2.0

## Objective

Find what creates **relevant follower conversion**, not merely impressions.

```text
AUDIENCE FIT
× VIEWPOINT / PRACTICE / CHANGE
× EVIDENCE
× HOOK
× DISTRIBUTION CONTEXT
-> STOP
-> ENGAGE
-> PROFILE INTEREST
-> FOLLOW REASON
-> FOLLOW
```

## Record Per Published Action

- `POST` or `REPLY`;
- content bucket: `WHAT_I_BELIEVE | WHAT_I_LEARNED | WHAT_CHANGES`;
- topic/thesis;
- evidence type: practice / primary source / data / case / synthesis;
- target account/post age for replies when available;
- reply-value type;
- language;
- hook;
- media/link treatment;
- impressions and engagement;
- profile visits when available;
- follower snapshots;
- qualitative follow-reason strength.

## Evidence Standard

- one result = anecdote;
- repeated similar results = hypothesis;
- a pattern is useful only when it helps relevant follower conversion or repeatedly produces strong profile/follow-reason evidence.

High-impression/zero-conversion reply patterns are explicitly **not** promoted as growth formulas.

## Current Hypotheses

1. first-hand practice and evidence outperform polished generic commentary;
2. clear theses outperform news summaries;
3. audience-relevant “so what” beats broad China-tech coverage;
4. reply distribution is useful only when the reply is uniquely valuable enough to trigger profile interest;
5. Chinese originals improve voice authenticity and recognizability;
6. China-side primary evidence can differentiate global AI/productivity discussions without defining the whole niche.
